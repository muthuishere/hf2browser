Chat with an LLM running in this tab

A converted model, quantized to q4, streamed from the Hugging Face Hub. Once it loads, everything — the model, the tool calls, the answers — happens on your machine.

The model downloads from the Hugging Face Hub the first time, then it is cached and later visits are instant. Nothing is uploaded, and no key is needed.

Tool calling needs the larger model: at q4 a 135M model chats fine but answers weather questions from imagination instead of calling the tool. A browser tab that is low on memory may fail on the 1 GB one — the smaller model always works.

Pick a model and press Load it to begin.




  The tools it can call — real JavaScript, edit and re-apply
  
Each tool(name, description, schema, handler) registers a function the
     model may call. Change one, hit Apply, and ask again — no reload.
