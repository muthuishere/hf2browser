hf2browser

Any Hugging Face LLM → running in your browser on plain CPU — with JavaScript tool calling. No WebGPU, no cloud.

GitHub Quick start 

git clone https://github.com/muthuishere/hf2browser && cd hf2browser
task up     # builds, serves, opens the browser — search → convert → chat

Search with tool-calling detection

Live HF Hub search flags which models can actually call tools, with size estimates before you download.

One-click conversion

ONNX export + q4 quantization, streamed live. New architectures auto-retry with a modern toolchain.

Verified, not assumed

Every conversion is behaviorally tested on CPU — including whether it really emits schema-valid tool calls.

browser-llm-nexus

Tiny runtime: register JS tools with JSON schema, get an agentic parse → execute → answer loop in the browser.

browser-llm-nexus in ten lines

import { NexusChat } from 'browser-llm-nexus';

const nexus = await NexusChat.load('Qwen/Qwen3-0.6B');
nexus.tool('get_weather', 'Current weather for a city',
  { city: 'string' },
  async ({ city }) => fetchWeather(city));

const answer = await nexus.chat('Weather in Chennai?');
// model calls the tool → your JS runs → grounded answer

The full app (conversion needs local compute + model storage) runs locally via task up. This page ships the browser-llm-nexus on npm.
